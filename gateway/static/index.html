Защита панели

  • Подписанная сессия, cookie HttpOnly и SameSite=Strict.
  • Автоматическое завершение сессии через 12 часов.
  • Блокировка IP на 60 секунд после 5 неверных паролей.
  • Флаг Secure для cookie при HTTPS через reverse proxy.

Рекомендуется публиковать панель через Nginx Proxy Manager с HTTPS. Не открывайте порт 8080 напрямую в интернет.
