Twemoji Country Flags font
==========================

Font file: TwemojiCountryFlags.woff2
Source: https://github.com/kutovoys/xray-checker
Polyfill implementation adapted from:
https://github.com/kutovoys/xray-checker/blob/main/web/static/country-flag-emoji-polyfill.js
Original polyfill project: https://github.com/talkjs/country-flag-emoji-polyfill

The font is generated from Twemoji Mozilla and contains country flag artwork.

supports ordinary emoji but does not render regional-indicator country flags.
