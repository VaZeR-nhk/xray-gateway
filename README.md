# Xray Gateway

Самостоятельный шлюз на базе **Xray Core**, Docker Compose и встроенной веб-панели.

> **Статус: ALPHA.** Проект тестируется. Не направляйте через него всю рабочую сеть до прохождения контрольного списка.

## Архитектура и хранение данных

Установка выполняется в `/opt/xray-gateway`.

- `.env` — единственный источник настроек и секретов: URL подписки, учётные данные Web UI, версия Xray и параметры маршрутизации. Права файла — `600`, в Git он не попадает.
- `state/` — рабочее состояние: постоянный HAPP HWID, JSON подписки, активный профиль, текущая и последняя рабочая конфигурации.
- `gateway/` — приложение и Web UI.
- `docker/` — конфигурация контейнера и планировщик обновления.
- `install.sh` — подготовка ОС, проверка, сборка и запуск.

Старый каталог `data/`, файлы `settings.conf` и native-установка не читаются и не импортируются. Миграция со старой архитектуры в тестовой ветке не поддерживается. Для новой установки используйте чистый сервер.

## Требования

- Debian 12 или Debian 13.
- amd64 или arm64.
- Root и systemd.
- Доступ к APT, Docker Hub и GitHub.
- HTTPS URL подписки Remnawave.
- Не менее 1 GiB свободного места на разделе проекта и Docker.

## Установка

Выполнить от root на чистом Debian 12/13:

```bash
apt-get update
apt-get install -y git
mkdir -p /opt/xray-gateway
cd /opt/xray-gateway
git clone https://github.com/VaZeR-nhk/xray-gateway.git .
bash install.sh
```

Репозиторий публичный: GitHub Token не требуется. `git clone` сразу получает актуальную версию проекта. Файл `.env` и каталог `state/` исключены из Git через `.gitignore` и не загружаются из репозитория.

При установке вводится HTTPS URL подписки (отображается открыто), логин Web UI и пароль (пароль вводится скрыто; можно сгенерировать автоматически). После успешной установки адрес панели, логин и пароль выводятся в консоль. Пароль также хранится в `/opt/xray-gateway/.env` с правами `600`.

Установщик выполняет проверки синтаксиса, Docker Compose, сборку образа и container smoke test до замены работающего контейнера. TPROXY по умолчанию выключен.

## Подписка и профили

- Подписка загружается с Remnawave JSON endpoint `/json` с HAPP-заголовками и постоянным HWID.
- Если URL не оканчивается на `/json`, endpoint дополняется автоматически.
- HWID создаётся один раз и сохраняется в `state/hwid`.
- JSON подписки сохраняется без фильтрации профилей и узлов.
- Обновление подписки выполняется каждый час.
- Активный профиль автоматически не переключается.
- Профиль меняется только вручную из Web UI/API.
- Перед применением конфигурация проверяется через `xray run -test`.
- При неудачном применении сохраняется предыдущая рабочая конфигурация.

## Проверка узлов

Проверка запускает отдельные временные процессы Xray и локальные SOCKS-порты. Она не перезапускает основной Xray, не меняет активный профиль и не фильтрует подписку. Используется HTTP-проверка `www.gstatic.com/generate_204`; неуспешный ответ сам по себе не доказывает полную неработоспособность узла.

## Прозрачная маршрутизация (TPROXY)

TPROXY не включается автоматически. Сначала проверьте подписку, профили, ручное переключение и Web UI.

После проверки настройте маршрутизацию отдельно:

```bash
cd /opt/xray-gateway
bash host-network.sh install
```

Скрипт запросит LAN-интерфейс и IPv4-подсеть. Пример:

```bash
bash host-network.sh install br0 192.168.12.0/24
```

Реализация перехватывает только IPv4. Сначала проверьте на одном тестовом клиенте. Откат:

```bash
bash host-network.sh uninstall
```

## Обновление и диагностика

```bash
cd /opt/xray-gateway
bash update.sh
docker compose ps
docker compose logs --tail=100
docker compose exec xray-gateway supervisorctl status
```

Для обновления исходников используйте обычный Git из каталога проекта:

```bash
cd /opt/xray-gateway
git pull --ff-only origin main
bash install.sh
```

Файл `.env` и каталог `state/` исключены из Git через `.gitignore`: обычный `git pull` их не сравнивает, не перезаписывает и не удаляет. Остальные локальные изменения Git может не дать обновить — их нужно отдельно проверить, не применяя `reset --hard` или `git clean`.

## Остановка

```bash
cd /opt/xray-gateway
bash uninstall.sh
```

Контейнер удаляется, но `.env` и `state/` сохраняются. Docker Engine и его системное хранилище не удаляются.

## Контрольный список перед эксплуатацией

1. Контейнер и процессы Xray/Web UI имеют статус RUNNING.
2. Подписка загружена, все профили отображаются.
3. Ручное переключение профиля подтверждается.
4. Проверка узлов не влияет на основной Xray.
5. Web UI доступен только из доверенной сети.
6. TPROXY сначала проверен на одном клиенте.
7. Проверены DNS, TCP, UDP, локальные подсети и исключения.
8. После перезагрузки восстановились контейнер и необходимые сетевые правила.
9. Проверен сценарий отката.

До завершения проверок проект следует считать тестовой сборкой, а не production-шлюзом.
